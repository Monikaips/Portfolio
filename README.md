# Monika P - Portfolio

A modern, responsive portfolio website for Monika P, a Full Stack Developer specializing in React, TypeScript, FastAPI, and AWS.

## Features

- **Modern UI/UX**: Clean, professional design with smooth animations
- **Responsive Design**: Fully responsive for all screen sizes
- **Dark/Light Mode**: Toggle between dark and light themes
- **Animations**: Smooth transitions and hover effects using Framer Motion
- **Performance Optimized**: Fast loading times and optimized assets
- **SEO Friendly**: Proper meta tags and semantic HTML

## Technologies Used

- **Frontend**: React.js, TypeScript, Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: React Icons
- **Build Tool**: Vite
- **Deployment**: GitHub Pages

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

### Development

To start the development server:
```bash
npm run dev
```

### Build

To create a production build:
```bash
npm run build
```

### Preview

To preview the production build:
```bash
npm run preview
```

## Deployment

The portfolio is configured for deployment to GitHub Pages. To deploy:

1. Update the `base` property in `vite.config.ts` to match your GitHub username and repository name:
   ```typescript
   base: '/your-username/your-repo-name/'
   ```

2. Build the project:
   ```bash
   npm run build
   ```

3. Deploy to GitHub Pages using the `gh-pages` package or GitHub Actions.

## Customization

To customize the portfolio for your own use:

1. Update the content in the component files in `src/components/`
2. Replace placeholder images with your own
3. Update contact information in `src/components/Contact.tsx`
4. Modify the color scheme in `tailwind.config.js`
5. Update meta tags in `index.html`
